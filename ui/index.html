Project Understanding
Auto-derived summaries from observations · Last updated 2 min ago
What this project does

MemKit is an MCP server plugin for Claude Code that wraps the raw memory storage layer with intelligent, relevance-gated injection. Instead of dumping all past observations into every session, it scores each one by specificity, actionability, and recency decay — then greedily fills a token budget with only the highest-scoring observations that match the current task context. It stores everything in a self-contained SQLite sidecar database with FTS5 full-text search, making it fully independent of any external memory tool.

Key Concepts
Relevance-gated injection
Observations scored and filtered before session start. Only top-N by finalScore × recencyDecay are injected.
FTS5 BM25 search
SQLite full-text search with built-in BM25 ranking. Zero external deps, deterministic, fast for <10k observations.
Token budget
Per-session token budget (default 2000). Greedy fill: largest-signal obs first until budget exhausted.
Decay scoring
score × e^(-0.03 × days_old). ~23 day half-life. Old observations fade out without explicit deletion.

Business Insights
What this product does, who it's for, and key business rules
Product in one paragraph

MemKit is a developer tool that makes AI coding assistants smarter over time without wasting tokens. It sits between Claude Code and its memory layer, deciding which past context is worth injecting into each new session based on relevance to the current task. The target user is a developer who uses Claude Code daily across multiple projects and wants the AI to "remember" patterns, constraints, and decisions without paying the token cost of injecting everything every time.

Target users

Daily Claude Code users managing multiple codebases. Developers building AI-assisted workflows. Teams where coding context needs to persist across sessions.

Core value proposition

57% average token savings with better context quality than naive injection — Claude gets the right past knowledge, not all past knowledge.

Key Business Rules
📐
Budget is hard-capped, not advisory
2000 token default. Observations never injected over budget — greedy fill stops.
⏱
23-day half-life on all observations
Old context fades. No manual expiry needed. λ=0.03 is tunable per project.
🔍
min_relevance_score = 0.4 gate
Below threshold, observations never surface — even if budget allows. Quality beats quantity.

Who are the main competitors?
M
Based on the codebase, MemKit was explicitly built against claude-mem (thedotmack). The key differentiators are: self-contained SQLite (no OAuth), rule-based compression (no LLM cost), and quality scoring with decay. Closest competitors: claude-mem, Mem0, and any future native Claude memory. The moat is the token budget + scoring layer — those don't exist elsewhere yet.
